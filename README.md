# 决战OL（JZOL）本地服务端重建工程

> 非官方 · 停服游戏怀旧重建 · 仅学习研究用途 · 不用于任何商业目的

## 这是什么

《决战OL》是掌中酷柚（KooGame）开发的回合制手机网游，2011 年公测，后由咪咕接手运营并最终停服。
本工程基于**客户端解包逆向成果**（客户端 Lua 逻辑、协议、接口字典），从零重建了可运行的本地服务端，
目标是让原版客户端通过 hosts 指向/协议改写连上本地服务器，恢复"登录 → 角色创建 → 新手引导 → 进村"等核心流程。

**注意：本仓库不含任何客户端资产**（APK、Lua 脚本、pk3 资源包、美术资源等均不提供）。
客户端资产版权属于掌中酷柚/咪咕，请自行考古获取。

## 服务端运行

### 方式一：直接运行 jar（需 Java 17+）

```bash
java -jar server-springboot/jzol-server.jar
```

默认端口见 `application.yml`（9080 系列）。客户端需通过 hosts 或客户端地址改写指向本地。

### 方式二：源码构建（需 Maven）

```bash
cd server-springboot
mvn package
java -jar target/jzol-server.jar
```

数据库使用 H2 内嵌（`schema.sql` 自动初始化），无需安装 MySQL。

## 对接客户端（重要）

- 客户端服务器地址（原）：`koogame.jzOL` / `koogame.cn:9082/9080` / `litchi.koogame.cn:8080` / `gamepie.g188.net` 等
- 本地联调：通过 hosts 将上述域名指向 `127.0.0.1`，或修改客户端 APK 内地址常量
- 协议为 HTTP GET/POST（Servlet 风格，UTF-8 响应，详见 `docs/决战OL_Servlet接口蓝图.txt`）
- 部分接口走二进制/TCP（NetRecv 直连），联调时用 Wireshark 抓帧对照 `docs/协议提取_战斗链路.txt`
